# PipeERP v0.3.0

نسخة Windows مستقرة ومجهزة للتثبيت والتحديث الآمن.

## الجديد

- فواتير بيع بالوزن مع احتساب الوزن الفعلي وسعر الكيلو.
- كشف حساب مستقل للعميل وتوزيع التحصيل على أكثر من فاتورة.
- أرصدة افتتاحية محاسبية للعملاء والموردين مع سجل تدقيق وعكس القيود.
- إتمام تصنيع مبسط مع إنشاء الدفعات تلقائيًا عند إدخال الإنتاج النهائي.
- إمكانية استبعاد خامة من التشغيلات التالية دون تغيير التشغيلات السابقة.
- تحسين مظهر البرنامج في الوضعين الفاتح والداكن وتوسيع إعدادات الخط والواجهة.
- تصفير الحركات التشغيلية مع الحفاظ على الأصناف والعملاء والموردين والخلطات.

## حماية البيانات

- تحفظ قاعدة البيانات والإعدادات والنسخ الاحتياطية خارج مجلد تثبيت البرنامج.
- تثبيت التحديث فوق النسخة الحالية لا يحذف بيانات العميل.
- تُطبق ترقيات قاعدة البيانات تلقائيًا حتى Schema 11 مع الحفاظ على البيانات القديمة.
- يتضمن البناء الآلي اختبار تشغيل للنسخة المجمعة واختبار إعادة التثبيت مع التحقق من
  بقاء قاعدة البيانات.
