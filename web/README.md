# PipeERP Web

إعادة بناء تطبيق PipeERP للويب اعتمادًا على قواعد العمل المثبتة في تطبيق سطح المكتب.

## المبادئ

- PostgreSQL هو مصدر الحقيقة الوحيد.
- الحسابات المالية والأوزان تستخدم `Decimal`/`NUMERIC` فقط.
- الصلاحيات تُفرض في الـ API ولا تعتمد على إخفاء عناصر الواجهة.
- المخزون وFIFO والتصنيع ينفذون داخل معاملات ذرية مع حماية التزامن.
- البيع بالقطعة والبيع بالوزن مساران أساسيان من الإصدار الأول.
- الطباعة المستهدفة A4 فقط؛ لا توجد طباعة حرارية في تطبيق الويب.
- كل وحدة تُسلّم مع اختبارات الوحدة والتكامل والواجهة اللازمة لها.

## الهيكل

```text
web/
├── backend/       FastAPI + SQLAlchemy + Alembic
├── frontend/      React + TypeScript + Vite
├── docs/          قرارات المعمارية والأمان والاختبارات
├── compose.yaml   بيئة التطوير المحلية
└── .env.example   أسماء المتغيرات المطلوبة دون أسرار
```

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` وضع قيمًا محلية قوية.
2. شغّل `docker compose up --build` من داخل مجلد `web`.
3. الواجهة: `http://localhost:5173`.
4. توثيق API: `http://localhost:8000/api/docs`.

> هذه نقطة تأسيس أولى. الوحدات التشغيلية ستُضاف كشرائح رأسية: قاعدة البيانات، ثم الخدمة، ثم API، ثم الواجهة، ثم الاختبارات.
