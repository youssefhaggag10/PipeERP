# خريطة مراحل PipeERP Web

آخر تحديث: 18 أغسطس 2026

## قاعدة إدارة العمل

- توجد مرحلة واحدة فقط بحالة **قيد التنفيذ**.
- لا تُغلق المرحلة لمجرد انتهاء كتابة الكود.
- الإغلاق يتطلب نجاح الكود والاختبارات والأمان وواجهة الاستخدام وCI.
- أي خلل يظهر بعد الإغلاق يُسجل كتراجع مرتبط بالمرحلة ويُعالج قبل الإصدار.

### شرط الإغلاق

لا تُغلق المرحلة 2 حتى يثبت الاختبار أن مستخدمًا بلا صلاحية لا يستطيع تنفيذ العملية حتى لو استدعى الـAPI مباشرة، وأن تعطيل الحساب أو إبطال الجلسة يمنع الاستخدام فورًا.
